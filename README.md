# 🔔 スタートブザーくん

競泳の練習で使う **スタート合図ブザー** です。
ピッ、ピッ、**ピーーー！** のリズムで、同じコースの全員が気持ちよくスタートできます 🏊

---

## 🚀 はじめかた（3ステップ）

1. `index.html` をダブルクリックしてブラウザで開く
2. 下の3つの設定を決める
3. **「開始」** を押す。押した瞬間に1番目のスタート音が鳴ります！

インストールもネット接続も不要です。スマホ・タブレット・PCのブラウザで動きます。

---

## 🎛 設定のしかた

| 項目 | 選べる範囲 | ひとこと |
|---|---|---|
| ⏱ スタート音の間隔 | 1〜60秒 | スタート音から次のスタート音までの間隔 |
| 🔉 短音の回数 | 0〜4回 | スタート音の前に鳴らす「ピッ」の数 |
| 🔁 繰り返し回数 | 0〜1000回 / エンドレス | 何回スタート音を鳴らすか |

範囲を外れた数字を入れると、赤いメッセージでお知らせします。

---

## 🎵 どんな音が鳴るの？

**短音 2回 ・ 間隔 10秒** の場合：

```
0秒    スタート音 ━━━━━━━━ (1秒)
8秒    ピッ
9秒    ピッ
10秒   スタート音 ━━━━━━━━ (1秒)
18秒   ピッ
19秒   ピッ
20秒   スタート音 ━━━━━━━━ (1秒)
```

- 🔸 **短音** は 0.1秒の短い音
- 🔹 **スタート音** は 1秒の長い音（短音より高い音）
- ⏱ 短音は、スタート音の **1秒前・2秒前…** に鳴ります
- 📏 音の間隔は、**鳴り始めから鳴り始めまで** がきっちり **1.000秒**
- 1番目のスタート音の前には短音は鳴りません（押してすぐスタート！）
